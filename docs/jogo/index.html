Controles da aventura

No computador: WASD/setas para andar em relação à câmera, Ctrl para travar/destravar a mira no inimigo visível mais alinhado, Shift para correr, Q para esquivar na direção do movimento (ou para onde o herói olha se estiver parado), Espaço para pular, botão esquerdo para atacar, botão direito e arraste para girar a câmera, roda do mouse para aproximar ou afastar e E para interagir com baú ou portal. Com a mira travada, frente/trás aproxima ou afasta e esquerda/direita circula o alvo. No controle PS4: analógico esquerdo move, direito gira a câmera, Quadrado ataca, X pula, toque no Círculo esquiva e segurar Círculo corre, Triângulo interage, R3/L1/R1 alternam a mira, D-pad também move; L2 corre e R2 ataca. No celular, use o direcional e os botões na tela; deslize sobre o mundo para mover a câmera e use dois dedos para aproximar ou afastar.
